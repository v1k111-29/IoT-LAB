# Foundations of IoT Laboratory

Lab experiment submissions, organised by hardware platform and experiment (CAT) identifier.

```
8051/   CAT2 ... CAT7   AT89S52 + Keil uVision (C51)
STM32/  CAT8 ... CAT14  STM32 Nucleo / Blue Pill + CubeMX, CubeIDE or Keil MDK
```

Each experiment folder holds its own `README.md` (EXP, DATE, NAME OF EXP, HARDWARE SETUP / PLATFORM, TASK NO, Circuit Diagram, Core Logic, INFERENCE), `circuit.png` and the project files.

Wi-Fi SSID and password in the ESP8266 experiments are placeholders. Set your own before building.
